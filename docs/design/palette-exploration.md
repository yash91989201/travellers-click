# Homepage palette exploration

Status: decision recorded, 2026-11-12. The existing slate-and-coral palette remains selected; its hex values did not change. The exploration controls are no longer part of the homepage.

The user confirmed a warm, personal, approachable, adviser-led direction while keeping the overall page layout. They rejected cobalt and citron as too sporty, forest and marigold as generic, and aubergine as a poor fit. No replacement palette was adopted.

The selected visual treatment uses warm ivory and white as the reading surfaces, mist for the enquiry region, slate for structure and the review section, and deep ink for the footer. Coral stays focused on the main enquiry action. Lora and Figtree remain the heading and body fonts; the redesign uses mostly normal or medium heading weights, clearer spacing, and lighter solid rules.

The existing hero photography, localized neutral scrim, destination pin motion, and overlapping discovery form remain. The page keeps its broad section order, travel-style mosaic, package accordion, and review interaction. Decorative looping route graphics and benefits sequence numbers were removed. Package content remains illustrative. Invented sample quotes were replaced with non-testimonial review placeholders; no business claims or facts were added.

This note records the design decision and scope. It does not claim that visual, accessibility, or release validation has passed. See `DESIGN.md` for the current palette and visual rules.

## Typography integration

The typeset pass incorporates main commit `c365f2a` and its named typography
roles, larger UI labels, and readable input values. Browsing headings use
32–42px, supporting bands 26–30px, and enquiry 36–48px; Lora 500 retains the
warmer treatment. Actual Lora italic font assets are loaded for the destination
and process numerals. The detector's 44px hero advisory are intentional
responsive endpoint documented in DESIGN.md, not additional role sizes.
